## 环境要点（重要）
- **npm install 在本项目中文路径 `F:\ZBL\ZBL主页\...` 下会失败**：npm tar 解压把路径编码成 GBK 乱码（`ZBL涓婚〉`），报 TAR_ENTRY_ERROR ENOENT。
- 但 `astro build` / `astro dev` 在该中文路径下**可正常运行**（Vite 处理 UTF-8 路径正常）。
- 绕过办法：复制到英文路径（如 F:\devportfolio-build）npm install 后，把 node_modules 拷回原目录即可。
- 运行方式（避免走 npm）：`node node_modules/astro/astro.js dev|build`。
- PowerShell 工具的 stdout 不回传，需要把输出 `Out-File` 到文件再读。
- 项目 package.json 是 `"type": "module"`，临时脚本要用 `.mjs` + `import` 语法。
- 中文字体：模板用 IBM Plex Mono，无中文字形，中文会回退系统字体，观感不一致 —— 待问用户是否换字体。
